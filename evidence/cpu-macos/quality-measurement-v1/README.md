Each distinct saved SHA/reference mode receives full `ffprobe -show_frames` evidence and two FFmpeg metric filters. Exactly 300 ordered PSNR and SSIM rows must exist. Per-frame reports include Y/U/V and the weighted all-plane result. Aggregates include pooled MSE/PSNR, the separately retained FFmpeg aggregate PSNR line, finite-frame mean PSNR, infinite-frame count, mean SSIM, minima, and worst zero-based frame indexes. PSNR uses FFmpeg's 8-bit peak 255, including for limited-range samples. Text statistics have FFmpeg's printed precision; pooled/mean values derived from those rows have that precision, while the raw aggregate log remains available. `inf` stays an explicit string rather than invalid JSON. Quality has **no arbitrary pass threshold**.

Cadence checks actual integer `pts × time_base` against `index / 30`, not rounded display timestamps or average FPS alone. The report retains every actual PTS, best-effort timestamp, available DTS/duration, picture type, and rational interval; count, rate, and available duration mismatches are reported. Metrics normalize filter PTS to frame index only after collecting actual cadence, so an irregular delivered timeline is not hidden by FFmpeg framesync. A failed cadence is reported distinctly from metric computation. Missing/incorrect format or frame count prevents a valid 300-frame quality result. Identical output bytes reuse the same quality/cadence result across original repeats; source mode is kept in the deduplication key so a strict CPU reference can never be borrowed from a legacy run.
