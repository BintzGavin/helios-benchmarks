# Preservation and provenance

Original evidence is copied or uploaded byte-for-byte, with its original SHA-256 and size. Absolute machine paths inside JSON/logs remain provenance, not executable instructions or live public links. Derived summaries are separate from raw receipts; archived dates and scopes are not retroactively edited. Duplicate media can share one published content-addressed object while each original path remains cataloged.

Source snapshots, fonts, runtime binaries and third-party code retain their upstream license notices and terms. Public repository visibility is not a blanket relicensing of those materials. Original license/OFL/COPYING/NOTICE files and source archives are included where retained. Benchmark output, data, scripts and original project code must be interpreted with their recorded provenance.

Dependency/build caches, Git internals, credential/configuration material, private conversation transcripts, unrelated marketing assets and still-active non-final experiments are outside this evidence snapshot. These exclusions do not remove failed benchmark attempts, old oracle corrections, original/repaired outputs or recorded source/runtime hashes. The Linux raw-media transfer gap is documented rather than hidden behind a compact-package completeness claim.
