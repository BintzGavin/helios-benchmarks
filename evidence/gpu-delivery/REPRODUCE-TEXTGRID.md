# Reproduce the frozen TextGrid baseline

This package records the completed TextGrid study. It does not include a qualified4K comparison or an end-to-end zero-copy proof. Preserve the original hash manifest and receipts; new runs require fresh host/source/reference qualification.

1. Install compatible macOSarm64 Node22, Rust1.97.1, FFmpeg9.0.2 with libx264/VideoToolbox, and Chrome154.0.8037.97. Read preparation/README.md, its explicit prerequisites, comparison/PROTOCOL.md and the native portable GPU-PROTOCOL.md from the included source archive. These are source pins, not promises that differently versioned tools reproduce identical results.
2. Recover the full fframes workspace at f89cbd572524b70a709ba3569fa23b0bbc8a0d9c. The GitHub codeload archive URL is https://codeload.github.com/dmtrKovalenko/fframes/tar.gz/f89cbd572524b70a709ba3569fa23b0bbc8a0d9c ; expected bytes610334707 and SHA256a195da36486fb9a5c5914760e410f36c387b54e733634e04cd8789fbe7f3f2ae. The package includes the changed TextGrid adapter source and actual-hardware diagnostic patch. Recover missing unchanged workspace directories from that exact source. Retain MIT/LICENSE notices.
3. Recover the Helios portable source from comparison/frozen-native-baseline.tar, pin478035260fb5c0ae5a391e9b66bacee19a7a9ffa. Frozen native binary and fframes adapter are under comparison/frozen with hashes in their receipts. Release build logs, Cargo lock and dependency pins document the source-to-binary bindings. Do not substitute Helios Skia0.91 libraries for fframes Skia0.153.3.
4. Relocate only executor paths in checkpoint/export-comparison.mts, export-remotion.mts and config preparation. Record those edits and new hashes. Remotion's baseline source/project is pinned in its adapter/provenance; recover its equivalent3334-label scene and exact4.0.529 dependency from the documented CPU benchmark project. Use one Chrome tab.
5. Run the25 preparation tests and checkpoint/test_comparison_schedule.py. Perform fresh actual-device/hardware probes and excluded adapter smoke tests. Generate per-engine lossless references; bind the native hardware reference to direct NV12 plane bytes without color arithmetic. Screen every300-frame output at the exact floors before marking anyengine ready.
6. Build new hash-bound configs with checkpoint/prepare-comparison-config.py. Run preparation/run_matrix.py with --execute, sanitized current-host preflight and a new empty output directory. Run engines sequentially; use the four balanced rounds, one excluded warmup, one common full post-export decode and excluded every-frame fidelity checks. Retain failed settings and attempts.

The existing raw receipts describe original absolute paths. All original candidate/reference videos remain locally retained; representative outputs are separate deliverables. A new run is a new measurement, not a relabeling of these clocks.
